# Tagless

Public hacker-facing site for Hack Club's Tagless YSWS: landing page, docs, project submission, gallery and stamp shop.

Next.js 16 app. Auth via Hack Club OAuth, time tracking via Hackatime, data in Airtable.

## Setup

```bash
cp .env.example .env.local   # fill in the values
npm ci
npm run dev
```

Review tooling and the admin dashboard live in a separate private repo.
