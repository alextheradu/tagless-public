# rules

1. **Only a few HTML tags are allowed.** You may write `<html>`, `<head>`, `<body>`, `<meta>`, `<title>`, `<script>`, `<style>`, and `<canvas>`. No `<div>`, `<p>`, `<span>`, `<h1>`, `<img>`, `<button>`, `<link>`, or any other HTML tags anywhere.
2. **No JSX.** JSX transpiles to HTML. JSX syntax is banned. `React.createElement` is fine.
3. **No AI.** Do not submit AI-generated code, images, writing, or other content. That includes GitHub Copilot, ChatGPT, and similar tools.
4. **Must render in a browser.** Whatever you build must be viewable at a public URL.
5. **Minimum 4 hour** of Hackatime project time.
6. **Must be hosted on an always on platform** (e.g. Vercel, Nest, Github Pages, etc). No railway, glitch, or other platforms that sleep after a period of inactivity.
7. **Make it yours.** If you follow a tutorial, you must add a significant amount on top of it. Copying a tutorial isn't your project.
8. **High school students or younger.** Hack Club YSWS eligibility rules apply.
9. **No double dipping.** Do not submit the same project to multiple YSWSs.
10. **No fraud.** Fraud can get you banned from Hack Club and affiliated programs. Examples include submitting someone else's project, using AI to generate a project, tricking Hackatime, or lying about your work.
11. **Breaking these rules may result in a ban from Hack Club and affiliated programs.**
