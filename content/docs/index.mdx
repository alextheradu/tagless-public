# what is tagless?

Tagless is a Hack Club YSWS (You Ship We Ship). Ship a website without using disallowed HTML tags: not in raw HTML, not in JSX, and not anywhere else in your codebase.

You are allowed to use these literal tags: `<html>`, `<head>`, `<body>`, `<meta>`, `<title>`, `<script>`, `<style>`, and `<canvas>`. Everything else should be created without writing HTML tags directly.

**Ship it and claim your free luggage tag.** Every hour past the 4-hour minimum also earns shop stamps!
