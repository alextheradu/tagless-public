# resources

## Ways to build without disallowed HTML tags

The core constraint: only `<html>`, `<head>`, `<body>`, `<meta>`, `<title>`, `<script>`, `<style>`, and `<canvas>` are allowed as literal tags. No other `<tags>` - not in `.html` files, not in JSX, not in template strings.

Start with one of these approaches:

- [Canvas API](/docs/resources/canvas-api)
- [WebGL / Three.js](/docs/resources/webgl-threejs)
- [React without JSX](/docs/resources/react-without-jsx)
- [CSS pseudo-elements](/docs/resources/css-pseudo-elements)
- [WebAssembly](/docs/resources/webassembly)
- [Python in the browser](/docs/resources/python-in-browser)
- [p5.js](/docs/resources/p5js)
- [SVG via JavaScript](/docs/resources/svg-via-javascript)
- [Starter ideas and general tips](/docs/resources/starter-ideas-and-tips)
